# E-commerce Core

Учебный проект по объектно-ориентированному программированию.

## Описание

Реализовано ядро интернет-магазина (e-commerce), включающее базовые
сущности: товары и категории.

Проект построен с использованием src-layout и современных инструментов
разработки.

## Реализованный функционал

### Абстрактный класс `BaseProduct`

Создан абстрактный класс `BaseProduct`, реализованный с использованием `ABC`.

В нём выделена общая для всех продуктов функциональность:

- Абстрактное свойство `price`
- Абстрактный метод `__str__`
- Абстрактный метод `__add__`

Класс `Product` наследуется от `BaseProduct` и реализует все абстрактные методы.

Классы:

- `Smartphone`
- `LawnGrass`

наследуются от `Product`, тем самым сохраняя корректную иерархию классов.

### Класс-миксин `CreationLoggerMixin`

Реализован класс-миксин `CreationLoggerMixin`.

Миксин:

- Добавлен в цепочку наследования класса `Product`
- При создании объекта выводит в консоль информацию о том, какой класс был создан и с какими параметрами

Пример вывода:

```
Smartphone('Samsung Galaxy S23 Ultra', '256GB', 180000.0, 5)
```

### Класс Product

- `name` — название товара  
- `description` — описание  
- `price` — цена (приватный атрибут с геттером и сеттером)  
- `quantity` — количество в наличии (int)  

Дополнительно:
- Реализован `@property price`
- Реализован валидирующий `setter` (запрещает нулевую и отрицательную цену)
- Реализован `@classmethod new_product()` для создания объекта из словаря
- Переопределён метод `__str__`
- Реализован магический метод `__add__` для расчёта общей стоимости товаров

### Класс Category

- `name` — название категории  
- `description` — описание категории  
- `__products` — приватный список объектов `Product`  
- `category_count` — общее количество созданных категорий  
- `product_count` — общее количество товаров во всех категориях  

Дополнительно:
- Реализован метод `add_product()` для добавления товара
- Реализован геттер `@property products` для получения списка товаров в формате строки
- Переопределён метод `__str__`, который рассчитывает общее количество товаров на складе
- Реализована возможность итерации по товарам категории

### Абстрактный класс BaseModel

Создан абстрактный класс BaseModel, который выделяет общую функциональность для классов Category и Order.

В нём определён абстрактный метод:
- `__str__`

Классы Category и Order наследуются от BaseModel.

Это позволяет:
- избежать дублирования логики
- обеспечить единый интерфейс для моделей
- улучшить расширяемость архитектуры

### Класс Order

Реализован класс Order, который содержит:
- product — объект товара
- quantity — количество купленного товара
- total_price — итоговая стоимость

Ограничение:
- В заказе может быть указан только один товар.

Метод `__str__` возвращает информацию о заказе в читаемом виде.

### Классы-наследники Product

Добавлены два класса-наследника:

#### Smartphone
Дополнительные атрибуты:
- `efficiency` — производительность
- `model` — модель
- `memory` — объём встроенной памяти
- `color` — цвет

#### LawnGrass
Дополнительные атрибуты:
- `country` — страна-производитель
- `germination_period` — срок прорастания

### Метод middle_price()

В классе Category реализован метод подсчёта среднего ценника товаров.
- Складываются только цены (price)
- Деление происходит на количество товаров
- При отсутствии товаров возвращается 0
- Используется обработка ZeroDivisionError

### Ограничения
- Складывать можно только объекты одного класса (используется type()).
- При попытке сложить объекты разных классов выбрасывается TypeError.
- В категорию можно добавить только объект Product или его наследников (используется isinstance()).

## Обработка исключений

При создании Product с нулевым количеством выбрасывается:

```
ValueError: Товар с нулевым количеством не может быть добавлен
```
Реализовано пользовательское исключение `ZeroQuantityError`, которое используется:

- при добавлении товара в `Category`
- при создании `Order`

Используются конструкции:

- `try`
- `except`
- `else`
- `finally`

Сообщение о завершении обработки выводится в любом случае.
