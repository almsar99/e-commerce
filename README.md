# E-commerce Core

Учебный проект по объектно-ориентированному программированию.

## Описание

В рамках данного задания реализовано ядро интернет-магазина (e-commerce),
включающее базовые сущности: товары и категории.

## Реализованный функционал

### Класс Product
- name — название товара
- description — описание
- price — цена (float)
- quantity — количество в наличии (int)

### Класс Category
- name — название категории
- description — описание категории
- products — список объектов Product
- category_count — общее количество созданных категорий
- product_count — общее количество товаров во всех категориях

Атрибуты класса автоматически обновляются при создании новых объектов.

## Тестирование

- Реализованы тесты на корректность инициализации Product
- Реализованы тесты на корректность инициализации Category
- Проверяется подсчёт количества категорий
- Проверяется подсчёт количества товаров
- Покрытие функционального кода тестами более 75%

## Используемые технологии

- Python 3.13
- Poetry
- Pytest
- Pytest-cov
- Flake8
- Black
- isort
- mypy (strict mode)

## Запуск проекта

Установка зависимостей:

```bash
poetry install
```
Запуск тестов с покрытием:

```bash
poetry run pytest --cov=src
```

Запуск демонстрации:

```bash
poetry run python src/main.py
```
